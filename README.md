# Express Basics Assignment

A simple Express.js project demonstrating basic routing, dynamic route parameters, multiple route parameters, query parameters, and request logging.

## 📌 Project Overview

This project was created as part of an Express.js basics assignment.

The project demonstrates how an Express server handles different types of HTTP GET requests and sends responses to the client.

## 🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
- VS Code
- Git & GitHub
